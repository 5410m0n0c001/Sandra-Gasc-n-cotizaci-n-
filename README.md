# Cotización — Sandra, Banquete para Boda Civil

Generada a partir del `cotizac-n-Finca-las-isabeles-f` (plantilla universal de
Primavera Events Group). Cotización real para **Sandra**, Boda Civil, **19 de
diciembre de 2026**, **100 invitados**.

## A diferencia de una cotización de venue

Esta cotización **no incluye una locación de Primavera Events Group**: la
clienta aporta su propio jardín, que no cuenta con cocina ni fregadero.
Primavera lleva el banquete, el equipo de cocina móvil y el personal de
servicio directamente a ese jardín. Por eso no incluye secciones de datos
del recinto, ceremonia, DJ/pista/decoración ni croquis — esas cosas no
aplican a este servicio y no fueron cotizadas en la conversación real con
la clienta.
